# 电商客服业务规则

## 退款申请基础条件
当前订单退款接口仅接受状态为已支付、已发货或已完成的订单。退款申请需要商家审核；客服预检通过不代表审核通过，也不代表退款已经到账。退款申请必须由登录用户本人提交。

## 重复退款申请
订单存在待审核、已同意或已退款的申请时，不能重复创建退款申请。已拒绝的退款记录不属于活动申请，用户可以重新咨询并按页面流程重新提交。

## 多商家订单限制
当前在线退款流程不支持对包含多个商家商品的合并订单进行整单退款。遇到多商家订单时应转人工核实，不能承诺自动拆单退款。

## 订单取消
待支付和已支付订单可以进入取消流程；已发货、已完成、已取消或已退款订单不能通过普通取消流程取消。取消操作会由订单服务处理库存、优惠券及已支付金额回退，客服 Agent 不得直接修改订单状态。

## 物流信息边界
当前客服 Agent 没有连接物流轨迹服务。订单状态显示已发货时，只能说明订单已进入发货状态，不能据此编造承运商、物流节点或预计送达时间。

## 售后争议与人工处理
商品质量争议、赔偿、平台介入、多商家整单退款或业务数据异常应提供已核验事实并引导转人工。客服不能承诺商家审核结果、赔偿金额或到账时间。
